## Правила стиля

- Использовать короткие предложения и знакомые слова.
- Один абзац — одна мысль.
- Не повторять одну проблему в нескольких разделах.
- Не описывать внутренний процесс проверки.
- Не включать секреты и полные ответы API.
- Не добавлять техническую метрику только потому, что она собрана.
- Сохранять подробные доказательства во временных снимках, а в отчёт выносить только нужное backend-разработчику.
