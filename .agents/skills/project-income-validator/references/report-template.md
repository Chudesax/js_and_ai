## Правила итогового статуса

- `FAIL`: есть BLOCKER или HIGH, делающий текущий расчёт невозможным/ненадёжным.
- `PASS WITH WARNINGS`: расчёт возможен, но есть MEDIUM/LOW либо HIGH без влияния на текущие оплаченные операции; обоснование обязательно.
- `PASS`: подтверждённых нарушений нет; INFO-наблюдения допустимы.
