# Pink Finance

Учебное приложение на Vite и нативном JavaScript. Оно получает
финансовые данные из двух независимых API, учитывает успешные
операции, переводит суммы в USD и показывает отчёт на странице.

## Как движутся данные

```text
main.js
  │
  ├── api.js ─────────────── два финансовых источника
  │
  ├── salary.js
  │     ├── проверка ответов
  │     ├── фильтрация paid
  │     ├── объединение форматов
  │     └── currencyApi.js ─ один запрос курсов
  │
  └── ui.js ──────────────── отображение результата или ошибки
```

## Ответственность файлов

- `src/config.js` — адреса серверов и API-ключи.
- `src/api.js` — универсальный `request()` и запросы финансовых
  источников.
- `src/currencyApi.js` — один запрос к CurrencyFreaks за всеми
  необходимыми курсами.
- `src/salary.js` — проверка, фильтрация и финансовые расчёты.
- `src/ui.js` — создание интерфейса через нативный DOM API.
- `src/main.js` — последовательность запуска приложения.
- `src/style.css` — Tailwind и небольшие декоративные стили.
- `vite.config.js` — настройка Vite, Tailwind и пути GitHub Pages.
- `.github/workflows/deploy.yml` — автоматическая публикация сайта.

## Последовательность запуска

1. Браузер загружает `src/main.js`.
2. На странице появляется индикатор загрузки.
3. Два финансовых запроса выполняются параллельно.
4. `salary.js` проверяет ответы и оставляет нужные операции.
5. Все коды валют собираются в один список.
6. CurrencyFreaks вызывается один раз.
7. Операции группируются по валютам и переводятся в USD.
8. `ui.js` показывает общую сумму, карточки валют и курсы.
9. Нажатие на карточку открывает успешные операции этой валюты.
10. Любая ошибка перехватывается в `main.js` и показывается на
    отдельном экране.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-проверка:

```bash
npm run build
npm run preview
```

## Публикация на GitHub Pages

После отправки изменений в ветку `main` workflow автоматически:

1. устанавливает зависимости через `npm ci`;
2. запускает `npm run build`;
3. загружает папку `dist`;
4. публикует её на GitHub Pages.

В настройках репозитория должен быть выбран источник:

```text
Settings → Pages → Source → GitHub Actions
```

Для этого проекта адрес сайта:

```text
https://chudesax.github.io/js_and_ai/
```

Jekyll и ручная загрузка папки `dist` этому проекту не нужны.
